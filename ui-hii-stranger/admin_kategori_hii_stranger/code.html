Protokol Sistem 409 Conflict Aturan Integritas Data Toko

Kategori yang memiliki relasi produk aktif tidak dapat dihapus permanen. Permintaan delete pada taksonomi terhubung akan ditolak oleh API gateway dengan status 409 CONFLICT demi mencegah orphaned products dan riwayat nota pesanan rusak.

Solusi aman: Nonaktifkan status kategori untuk menyembunyikannya dari navigasi katalog pembeli tanpa merusak database.
