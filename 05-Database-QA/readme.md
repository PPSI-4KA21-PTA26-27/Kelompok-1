Dokumentasi Database Hii Stranger

Tanggal: 19 Oktober 2026

Melakukan perancangan dan dokumentasi struktur database PostgreSQL untuk aplikasi e-commerce Hii Stranger. Cakupan meliputi 16 tabel untuk pengelolaan akun pelanggan dan admin, kategori dan produk, varian serta stok, keranjang belanja, pesanan, pembayaran, dan tarif pengiriman. Perancangan juga mencakup relasi antartabel, primary key, foreign key, constraint, index, trigger, serta pengelolaan versi database melalui migration. Dokumentasi disusun berdasarkan pemeriksaan struktur database (schema dump) sebagai acuan pengembangan backend Go Gin.
